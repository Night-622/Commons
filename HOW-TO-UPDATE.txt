Commons update: how to install

The order matters this time: the new rules must be live before the new game goes out,
because the game now saves each city in two parts.

1. Open C:\Users\Other user\Desktop\Commons
2. Delete the old "public" folder and the old "test" folder.
3. Unzip this file into the Commons folder. It puts back:
     public\  (all the game files, plus manifest.webmanifest, icon.svg and sw.js)
     test\    (sim.test.mjs and balance.mjs)
     firestore.rules
     README.md
   Say yes to replacing firestore.rules and README.md.
   Don't touch anything else (firebase.json, .firebaserc, package.json, .github, .agents, .claude, .firebase).
4. FIRST, in a terminal in the Commons folder, run:
     npm run deploy:rules
5. THEN commit and push to GitHub. The Action deploys the website.
6. Open https://commons-ww.web.app and press Ctrl+F5.

Optional checks:
     npm test                 (simulation tests)
     node test/balance.mjs    (a scripted 100-day city; prints population, money and mood every 10 days)

Existing cities carry over: each one moves to the new two-part save the first time its mayor plays.
Feedback and support messages land in Firebase console > Firestore Database > feedback.
Chat reports land in the "reports" collection next to it.
